Notas del diseño

  • Alternancia: Blanco (#FFFFFF) ↔ Gris muy suave (#F9FAFB)
  • Sistema unificado: Cada sección usa el mismo spacing (py-16/py-20), tipografía Inter, y max-width contenido
  • React Islands: Solo Hero Carousel + Header — el resto es 100% Astro estático
  • CTA color: Rojo Condor (#E30613) para todos los botones de acción
  • Mobile: Stack vertical, secciones full-width, padding reducido
