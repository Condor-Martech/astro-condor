Home Page — 3 Approaches

Mismo contenido (10 secciones), diferente estructura y nivel de interactividad

A

Full Static + Minimal Islands

Idea: Todo Astro estático. React islands SOLO para el hero carousel y el header (como dice el spec). El resto son secciones HTML/CSS puras con hover effects via Tailwind.


Pros

  • Mínimo JS — ultra rápido (casi 0kb JS en body)
  • SEO perfecto, todo renderizado estático
  • Simple de mantener

Cons

  • Sin animaciones de entrada en secciones
  • El carousel necesita React igual
  • Se siente más "sitio estático" que "experiencia premium"
B

Static Sections + Scroll Animations (Recomendado ⭐)

Idea: Secciones estáticas en Astro, pero con un React island ligero que agrega animaciones de entrada (fade-in, slide-up) al hacer scroll via Framer Motion + Intersection Observer. Carousel y header como islands separados.


Pros

  • Sensación premium con animaciones sutiles al scroll
  • JS controlado — solo Framer Motion para animaciones
  • SEO sigue siendo excelente (contenido en HTML estático)
  • Equilibrio perfecto entre performance y experiencia

Cons

  • Más JS que approach A (~30-40kb Framer Motion)
  • Necesita client:visible para los islands de animación
C

Full React SPA-like

Idea: Toda la home como un gran React island. Animaciones complejas, transiciones entre secciones, parallax, efectos de scroll avanzados.


Pros

  • Máxima flexibilidad de animaciones
  • Experiencia tipo landing page de producto tech

Cons

  • Mucho JS — contradice la filosofía del spec ("sin JS innecesario")
  • SEO más débil (depende de hidratación)
  • Overkill para un supermercado institucional
  • Performance afectada en móviles
